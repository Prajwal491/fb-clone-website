# Facebook Clone Website

This project is a **Facebook website clone** that I created while learning and practicing **Git and GitHub**. The project helped me understand how to manage a project using Git, track changes, create commits, and upload and maintain code in a GitHub repository.

## 📌 About the Project

The Facebook Clone Website is a frontend project inspired by the design and layout of Facebook. It was created as a learning project to practice **web development concepts** while also gaining practical experience with **Git and GitHub version control**.

The main goal of this project was not to recreate the complete functionality of Facebook, but to understand how a real-world website can be structured and how Git can be used to manage development work.

## 🎯 Learning Objectives

Through this project, I practiced:

* Creating and managing a Git repository
* Tracking changes using Git
* Creating meaningful commits
* Working with GitHub repositories
* Uploading and managing project files
* Understanding Git workflow
* Practicing frontend website development
* Organizing files and project structure
* Making changes and updating the project using Git

## ✨ Features

The project contains a Facebook-inspired user interface with a layout designed to resemble a social media platform.

Some of the main elements include:

## 📚 Git Concepts Practiced

This project was also used to understand important Git commands and concepts such as:

```bash
git init
git status
git add .
git commit
git log
git branch
git checkout
git push
git pull
```

I learned how these commands are used to track project changes and synchronize a local project with a GitHub repository.

## 🚀 Purpose of the Project

This project was created mainly for **learning and practice**. It helped me gain hands-on experience with both frontend development and version control.

Building the project while following a Git tutorial allowed me to understand how developers manage their code, save different versions of their work, and collaborate using GitHub.
